# پل | Pol

[English](README.en.md)

کلاینت VPN برای OpenWrt با رابط LuCI، بر پایهٔ پروتکل‌ها و Worker پروژهٔ [BPB-VPN](https://github.com/bia-pain-bache/BPB-VPN).

- رابط فارسی و انگلیسی، راست‌به‌چپ و چپ‌به‌راست، با تم روشن و تاریک
- دکمه اصلی برای روشن و خاموش کردن سرویس
- اعمال مستقیم تنظیمات، بدون Save & Apply، با بازگشت خودکار در صورت شکست راه‌اندازی
- Worker روی Cloudflare، WARP، MASQUE و فرگمنت بدون سرور
- وارد کردن لینک VLESS، Trojan، SOCKS و HTTP یا خروجی‌های JSON هستهٔ Xray
- مسیریابی IPv4 و IPv6 دستگاه‌های LAN، DNS، دامنه‌های مستقیم و مسدود و پروکسی زنجیره‌ای
- گزارش زنده با فیلتر برنامه و هسته و امکان دریافت فایل گزارش
- بسته‌های جداگانهٔ `pol` و `pol-core` در هر دو قالب IPK و APK
- به‌روزرسانی مستقل برنامه و هسته با بررسی SHA-256 فایل انتشار

این پروژه پورت رابط Android نیست؛ رابط و سرویس OpenWrt را جداگانه پیاده می‌کند. قابلیت‌های مخصوص Android، مرورگر داخلی Browser Dialer، Domain Fronting با گواهی MITM و استقرار Cloudflare Pages در این نسخه ارائه نمی‌شوند. Tor و Psiphon از سرویس SOCKS محلی استفاده می‌کنند؛ باینری و مدیریت پل‌های این دو همراه بسته نیست.

## نصب

فایل‌های معماری روتر را از [Releases](https://github.com/dreamboxone/pol/releases) بگیرید. ابتدا هسته و سپس برنامه نصب می‌شود.

OpenWrt با APK:

```sh
apk add --allow-untrusted ./pol-core_26.10.21-r1_arm_cortex-a7_neon-vfpv4.apk ./pol_1.0.1-r1_arm_cortex-a7_neon-vfpv4.apk
```

OpenWrt با OPKG:

```sh
opkg install ./pol-core_26.10.21-1_arm_cortex-a7_neon-vfpv4.ipk ./pol_1.0.1-1_arm_cortex-a7_neon-vfpv4.ipk
```

صفحهٔ **Services → Pol** را باز کنید. در اولین نصب، سرویس خاموش است. وابستگی‌ها: `luci-base`، `rpcd`، `ca-bundle`، `ip-full`، `nftables` و `kmod-nft-tproxy`.

## اتصال Worker

1. در Cloudflare، یک API Token محدود به حساب موردنظر و مجوز Workers Scripts Edit یا نقش معادل Workers Admin بسازید.
2. زیر‌دامنهٔ `workers.dev` حساب را در Workers & Pages فعال کنید.
3. در زبانهٔ کلادفلر، توکن، Account ID و یک نام جدید برای Worker وارد کنید و ساخت Worker را بزنید.
4. دامنه و UUID به‌صورت خودکار ذخیره می‌شوند. توکن در تنظیمات یا گزارش‌ها ذخیره نمی‌شود.
5. در خانه، دکمه اصلی را روشن کنید.

ساخت Worker یک استقرار جدید در حساب Cloudflare ایجاد می‌کند و نام موجود را جایگزین نمی‌کند. اگر استقرار موفق شود ولی تنظیم محلی شکست بخورد، Worker در حساب باقی می‌ماند؛ آن را از داشبورد Cloudflare مدیریت کنید.

برای WARP یا MASQUE، در اتصال، دکمهٔ ساخت حساب مربوط را بزنید. ثبت حساب نیازمند دسترسی روتر به API سرویس Cloudflare است.

## شبکه و گزارش

مسیریابی شفاف فقط ورودی رابط LAN انتخاب‌شده را می‌گیرد؛ ترافیک خود روتر و دسترسی مدیریت دست‌نخورده می‌مانند. پروکسی SOCKS روی `127.0.0.1:24800` و HTTP روی `127.0.0.1:24801` فقط در خود روتر در دسترس‌اند. پورت‌های داخلی 24810 تا 24813 برای ورودی‌های شفاف و DNS رزرو شده‌اند. جدول مسیر 120 و بیت علامت `0x40000000` به سرویس اختصاص دارند.

هم‌زمان با یک پراکسی شفاف دیگر روشن نکنید. پل وجود جدول‌های شناخته‌شدهٔ زیرگذر، Passwall، HomeProxy و Nikki را بررسی می‌کند و برای جلوگیری از تداخل، شروع مسیریابی را رد می‌کند. در حالت پروکسی محلی، گزینهٔ اتصال تمام دستگاه‌های شبکه را خاموش کنید.

رویدادها در حلقهٔ محدود `logd` با برچسب‌های `pol-app` و `pol-core` ثبت می‌شوند. گزارش‌ها بعد از راه‌اندازی مجدد روتر حفظ نمی‌شوند. خروجی تنظیمات شامل اطلاعات حساس اتصال است.

فرگمنت بدون سرور، IP عمومی را عوض نمی‌کند و برای هر سایت یا شبکه تضمین اتصال ندارد. حالت Tor به SOCKS محلی روی پورت 9050 و Psiphon به پورت 10829 نیاز دارد.

## به‌روزرسانی

- هسته: فایل سازگار معماری از انتشار رسمی `XTLS/Xray-core` گرفته می‌شود؛ SHA-256 بررسی، فایل جدید آزمایش و در صورت شکست راه‌اندازی، نسخهٔ قبلی برگردانده می‌شود.
- برنامه: بستهٔ سازگار از `dreamboxone/pol` گرفته و با APK یا OPKG نصب می‌شود. این کار هسته را تعویض نمی‌کند. نتیجه در گزارش ثبت می‌شود و صفحه باید دوباره باز شود.
- عملیات طولانی در پس‌زمینه اجرا می‌شوند تا محدودیت زمانی rpcd مانع نشود.

## ساخت در WSL یا لینوکس

Go 1.26 یا جدیدتر، Python 3 و برای APK ابزار `apk` نسخهٔ 3 از SDK رسمی OpenWrt لازم است.

```sh
python3 build/fetch-core.py arm_cortex-a7_neon-vfpv4
export APK_BIN=/opt/openwrt-sdk/staging_dir/host/bin/apk
sh build/build.sh arm_cortex-a7_neon-vfpv4 both
```

خروجی‌ها در `dist/` نوشته می‌شوند. قالب دوم می‌تواند `ipk`، `apk` یا `both` باشد. معماری‌های قابل ساخت: `arm_cortex-a7_neon-vfpv4`، `aarch64_generic`، `aarch64_cortex-a53`، `x86_64`، `mips_24kc` و `mipsel_24kc`. آزمایش سخت‌افزاری فعلاً فقط برای ARMv7 انجام شده است.

```sh
go test -race ./...
go vet ./...
node --check package/pol/files/www/luci-static/resources/view/pol/main.js
```

Makefileهای SDK نیز در `package/` موجودند؛ ابتدا باینری‌ها را با اسکریپت ساخت آماده کنید. روش اصلی و آزمایش‌شده، `build/build.sh` است.
